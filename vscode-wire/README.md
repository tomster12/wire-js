# Wire.js for VS Code

Local extension for HTML files using Wire.js.

- Completion/hover for `<wire>` and `<component>` and their attributes
- JavaScript highlighting inside `{{ ... }}` (text and attribute values)
- `@signal` references and `arg:name` attributes highlighted
- Snippets: `wire-to`, `wire-to-expr`, `wire-with`, `wire-for`, `wire-if`, `wire-component`, `wire-instance`, `wire-state`, `wire-computed`

## Install

Copy or symlink this folder into `%USERPROFILE%\.vscode\extensions\wire-js-0.1.0` and reload VS Code.
Or run `npx @vscode/vsce package` here and use *Extensions: Install from VSIX...*.
