8Lists and scope

for repeats the content, and each names the item. The item is in scope for everything nested in the loop, including @{ } attributes of nested wires and components. Inside a template, {{ }} in a nested tag is plain text substitution, so arg:id="{{ todo.id }}" arrives as the string, while @{ } keeps its type. Data is never evaluated, as the third item shows.

9Components

A component's template sees only its own arguments and globals. Arguments you leave out arrive as null, @signal arguments are reactive, and @{ } arguments are evaluated when the instance renders and keep their type. 10Re-rendering and focus

A re-render replaces the element's children, unless the new HTML and items are identical to the last render. When children are replaced, the focused field gets its focus, typed text and caret back. Setting the same object forces a rebuild, because it may have been mutated.

13Edge cases

  • Always close the elements: <wire ...></wire>. The browser ignores /> and nests what follows.
  • A }} inside an expression ends it, so write {{ ({ a: { b: 1 } }).a }} with a space between closing braces.
  • A bare {{ x }} between attributes does not work in page markup, the browser turns it into attributes. Put it inside a quoted value.
  • On a page, {{ }} in a <wire> or <component> attribute throws. Inside a template it is substituted as text.
  • Substituted text is read as markup afterwards. A value that starts with @ or @{ in a nested tag attribute is read as Wire syntax, so substitute only values you control.
  • The content of a nested <wire> or <component> is not evaluated by the outer template. That element evaluates its own content with its own scope.
  • Expressions are compiled with new Function, so a Content Security Policy must allow unsafe-eval.
  • Signal and component names are global and unique. Registering a name twice throws.
  • State listeners run synchronously. Computed listeners and DOM updates run in a microtask.
  • Event handlers are plain inline attributes. Putting data inside one, such as onclick="f('{{ name }}')", can break out of the string, so pass an id instead.
  • Lists are rebuilt when their output changes, so a click that starts on a row that is replaced before release is lost. Use onmousedown for rows that change often.
  • Focus restore is best effort: it matches by position and does not restore scroll, other typed fields, or a pointer drag. Keep such controls outside the re-rendering wire.
  • class and style are plain attributes, never parsed as Wire syntax.
