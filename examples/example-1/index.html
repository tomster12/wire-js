1State and listeners

A State holds a value. Setting it notifies every listener, and <wire to="@count"> is simply a listener that writes the value into the page. listen() returns a function that removes the listener again.

2Computed

A Computed derives a value from other signals and recalculates whenever any of them changes. Computeds may depend on other Computeds, and may return anything, including markup.

3Shallow equality

set() compares the new value with the old one and stays silent when they are equal: the same reference, or an object or array whose entries are all identical. Replacing a value with an equal copy costs nothing, but mutating a value in place and setting the same reference is invisible to Wire.

4to: write a value into the element

to takes a signal or an expression and sets it as the element's HTML. An expression only re-runs when a signal attribute on the same element changes, so pair it with with. The element may not have child content. style is applied as written.

5with: re-render a template

Anything written inside a with element is a template. Each {{ }} holds a JavaScript expression with access to every global, and the whole template is evaluated again whenever the signal changes. The slider sits outside the element so it keeps focus while the text re-renders.

{{ withDemo.temperature.get() }} °C is {{ (withDemo.temperature.get() * 9 / 5 + 32).toFixed(1) }} °F. {{ withDemo.describeTemperature(withDemo.temperature.get()) }}

6if: show or hide

if takes a signal or an expression. When it is falsy the element is emptied and hidden; when it turns truthy the content comes back. It needs a content attribute (to, with or for) to say what to show. Signals are global, so these demos also read count from section 1.

8Components

A <component> without instance defines a template and declares its arguments with arg:name. With instance it renders that template, and each argument may be literal text, a signal, or an expression. Arguments you leave out arrive as null. A component may contain other components. An expression argument is evaluated when the instance renders and is not reactive on its own; pass a signal when you need it to follow changes.

9Everything together

A for loop renders a component for every row of a Computed, each row contains a nested <wire> bound to another signal, and an if reveals a summary once there is data. One rule matters when nesting: expressions inside a template are resolved while the template is hydrated, so by the time a nested element mounts they are already plain text. Pass loop values down as arg: literals, and keep nested <wire> attributes to signals.

Behaviours worth knowing

  • Signal names are global and unique. Registering a name twice throws.
  • Signals notify only when the new value is not shallow-equal to the old one.
  • Inside templates, expressions can use loop variables, component arguments, and any global.
  • Templates are read back through innerHTML, so avoid <, >, & and double quotes inside text expressions; put that logic in a function. Attribute expressions are read with getAttribute and are unaffected.
  • Expressions inside a template resolve when it hydrates, so nested elements receive plain text. Nested <wire> attributes should be signals.
  • An instance argument cannot be an empty value, and a literal beginning with @ is read as a signal.
  • Elements removed from the document are unsubscribed automatically.
